# Портал класу

Сайт школи з реєстрацією через заявку:

1. Людина заповнює заявку (учень, вчитель або батьки) і створює акаунт за поштою та паролем.
2. Поки адміністратор не схвалить заявку, видно лише екран «Очікуйте схвалення».
3. Після схвалення портал відкривається сам. У порталі:
   - **Чат класу** — в учня свій клас, у батьків клас дитини, вчителі й адміністратор обирають будь-який клас;
   - **Оголошення** — «Мій клас», «Уся школа», «Інші класи». Учні та батьки пишуть лише для свого класу, вчителі й адміністратор — для будь-якого або для всієї школи;
   - **Розклад** — поки заповнений лише для 6 класу;
   - **Окремі чати** — будь-хто створює чат і запрошує людей з будь-яких класів; чат і нові запрошення працюють лише після схвалення адміністратора;
   - **Підказки** — шпаргалки з головних предметів для 1–9 класів (файл `public/hints.js`);
   - **Заявки** — лише в адміністратора: заявки на вступ, нові чати й запрошення;
   - **Модерація** — хто з якого класу й коли заходив. Головний адмін змінює класи та призначає молодших модераторів.

| Хто | Що може |
|---|---|
| Головний адмін | Усе: схвалює заявки й чати, змінює класи, призначає й знімає модераторів |
| Молодший модератор | Видаляє повідомлення й оголошення, читає чати всіх класів, бачить «Модерацію» без зміни класів |
| Учень | Свій клас: чат, оголошення, розклад; окремі чати, куди його схвалено |

Сайт розміщується безкоштовно на GitHub Pages, дані зберігаються у Firebase (безкоштовний сервіс Google). Доступ перевіряє сервер Firebase за правилами з `firestore.rules`, тому без схваленої заявки до чату й оголошень не дістатися навіть в обхід сайту.

## Запуск — усе в браузері, ~10 хвилин

Потрібен акаунт Google (краще дорослого) і цей репозиторій на GitHub.

### 1. Firebase

1. Відкрийте <https://console.firebase.google.com> → **Створити проєкт** (Google Analytics можна вимкнути). Тариф Spark безкоштовний.
2. **Build → Authentication → Get started** → вкладка Sign-in method → **Email/Password** → Enable → Save.
3. Там само: вкладка **Settings → Authorized domains → Add domain** → впишіть `tymurius2-arch.github.io`.
4. **Build → Firestore Database → Create database** → регіон `europe-central2 (Warsaw)` → **Start in production mode**.
5. У Firestore відкрийте вкладку **Rules**, зітріть усе й вставте вміст файлу [`firestore.rules`](firestore.rules) → **Publish**.
6. **Project settings** (шестерня) → General → унизу **Your apps** → значок `</>` → будь-яка назва → Register app. З'явиться блок `const firebaseConfig = { ... }`.

### 2. Налаштування сайту

Скопіюйте блок `firebaseConfig` і надішліть його Claude — він вставить його в [`public/config.js`](public/config.js). Або вставте самі: відкрийте файл на GitHub → значок олівця → замініть значення → **Commit changes**. Ці налаштування не секретні, їх можна зберігати у відкритому репозиторії.

### 3. Публікація

1. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Злийте pull request із порталом у гілку `main` (кнопка **Merge pull request**).
3. За 1–2 хвилини сайт відкриється за адресою **<https://tymurius2-arch.github.io/jss/>**.

Далі будь-яка зміна в папці `school-portal/public` у гілці `main` публікується сама.

### 4. Перший адміністратор

Одразу після публікації, поки посилання ніхто не отримав:

1. Відкрийте сайт → **Заявка на вступ** → заповніть і надішліть.
2. На екрані очікування натисніть **«Стати адміністратором»**.

Кнопка працює один раз: після цього вона зникає в усіх, і ніхто інший стати адміністратором не зможе. Тепер можна розсилати посилання.

## Безпека

- Паролі зберігає Firebase, сайт їх не бачить. Забутий пароль відновлюється кнопкою «Забув пароль?».
- Чужі заявки бачить лише адміністратор.
- Читати й писати в чат можна лише свого класу; підписатися чужим іменем не можна.
- Адміністратор може видалити будь-яке повідомлення чи оголошення та закрити доступ.
- Сайт збирає мінімум даних: ім'я, клас, необов'язковий контакт. Не просіть адрес, телефонів дітей і фото документів.
- Дітям до 13 років варто реєструватися разом із батьками — за правилами Google і законом про захист даних потрібна згода батьків.

## Для розробників: перевірка без справжнього проєкту

```bash
npm install -g firebase-tools
firebase emulators:start --only auth,firestore,hosting --project demo-school
```
Відкрийте <http://localhost:5000/?emulator> — сайт працює з локальною тестовою базою.
