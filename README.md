# Портал класу

Сайт школы с регистрацией через заявку:

1. Человек заполняет заявку (ученик, учитель или родитель) и создаёт аккаунт по почте и паролю.
2. Пока администратор не одобрит заявку, виден только экран «Очікуйте схвалення».
3. После одобрения портал открывается сам. В портале:
   - **Чат класса** — у ученика свой класс, у родителей класс ребёнка, учителя и администратор выбирают любой класс;
   - **Оголошення** — «Мій клас», «Уся школа», «Інші класи». Ученики и родители пишут только для своего класса, учителя и администратор — для любого или для всей школы;
   - **Розклад** — пока заполнен только для 6 класса;
   - **Заявки** — только у администратора.

Сайт размещается бесплатно на GitHub Pages, данные хранятся в Firebase (бесплатный сервис Google). Доступ проверяет сервер Firebase по правилам из `firestore.rules`, поэтому без одобренной заявки к чату и объявлениям не добраться даже в обход сайта.

## Запуск — всё в браузере, ~10 минут

Нужен аккаунт Google (лучше взрослого) и этот репозиторий на GitHub.

### 1. Firebase

1. Откройте <https://console.firebase.google.com> → **Создать проект** (Google Analytics можно выключить). Тариф Spark бесплатный.
2. **Build → Authentication → Get started** → вкладка Sign-in method → **Email/Password** → Enable → Save.
3. Там же: вкладка **Settings → Authorized domains → Add domain** → впишите `tymurius2-arch.github.io`.
4. **Build → Firestore Database → Create database** → регион `europe-central2 (Warsaw)` → **Start in production mode**.
5. В Firestore откройте вкладку **Rules**, сотрите всё и вставьте содержимое файла [`firestore.rules`](firestore.rules) → **Publish**.
6. **Project settings** (шестерёнка) → General → внизу **Your apps** → значок `</>` → любое название → Register app. Появится блок `const firebaseConfig = { ... }`.

### 2. Настройки сайта

Скопируйте блок `firebaseConfig` и пришлите его Claude — он вставит его в [`public/config.js`](public/config.js). Или вставьте сами: откройте файл на GitHub → значок карандаша → замените значения → **Commit changes**. Эти настройки не секретные, их можно хранить в открытом репозитории.

### 3. Публикация

1. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Влейте pull request с порталом в ветку `main` (кнопка **Merge pull request**).
3. Через 1–2 минуты сайт откроется по адресу **<https://tymurius2-arch.github.io/jss/>**.

Дальше любое изменение в папке `school-portal/public` в ветке `main` публикуется само.

### 4. Первый администратор

Сразу после публикации, пока ссылку никто не получил:

1. Откройте сайт → **Заявка на вступ** → заполните и отправьте.
2. На экране ожидания нажмите **«Стати адміністратором»**.

Кнопка работает один раз: после этого она исчезает у всех, и никто другой стать администратором не сможет. Теперь можно рассылать ссылку.

## Безопасность

- Пароли хранит Firebase, сайт их не видит. Забытый пароль восстанавливается кнопкой «Забув пароль?».
- Чужие заявки видит только администратор.
- Читать и писать в чат можно только своего класса; подписаться чужим именем нельзя.
- Администратор может удалить любое сообщение или объявление и закрыть доступ.
- Сайт собирает минимум данных: имя, класс, необязательный контакт. Не просите адреса, телефоны детей и фото документов.
- Детям до 13 лет регистрироваться стоит вместе с родителями — по правилам Google и закону о защите данных нужно согласие родителей.

## Для разработчиков: проверка без настоящего проекта

```bash
npm install -g firebase-tools
firebase emulators:start --only auth,firestore,hosting --project demo-school
```
Откройте <http://localhost:5000/?emulator> — сайт работает с локальной тестовой базой.
