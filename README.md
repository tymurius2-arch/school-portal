# Портал класу

Сайт школы с регистрацией через заявку:

1. Человек заполняет заявку (ученик, учитель или родитель) и создаёт аккаунт по почте и паролю.
2. Пока администратор не одобрит заявку, виден только экран «Очікуйте схвалення».
3. После одобрения портал открывается сам, обновлять страницу не нужно. В портале:
   - **Чат класса** — у ученика свой класс, у родителей класс ребёнка, учителя и администратор выбирают любой класс;
   - **Оголошення** — фильтры «Мій клас», «Уся школа», «Інші класи». Ученики и родители публикуют только для своего класса, учителя и администратор — для любого класса или для всей школы;
   - **Розклад** — пока заполнен только для 6 класса;
   - **Заявки** — только у администратора: одобрить, отклонить, закрыть доступ, удалить.

Данные хранятся в Firebase (бесплатный сервис Google). Доступ проверяет сервер Firebase по правилам из `firestore.rules`, поэтому без одобренной заявки к чату и объявлениям не добраться, даже если обойти сам сайт.

## Файлы

| Файл | Что внутри |
|---|---|
| `public/index.html`, `public/style.css`, `public/app.js` | Сам сайт |
| `public/config.js` | Настройки вашего проекта Firebase и название школы |
| `firestore.rules` | Правила доступа к данным |
| `firebase.json` | Настройки публикации |

## Как запустить (нужен взрослый, ~20 минут)

1. **Проект Firebase.** Зайдите на <https://console.firebase.google.com>, нажмите «Создать проект». Тариф Spark бесплатный, карта не нужна.
2. **Вход по почте.** Build → Authentication → Get started → Sign-in method → **Email/Password** → Enable.
3. **База данных.** Build → Firestore Database → Create database → регион `europe-central2 (Warsaw)` → **Production mode**.
4. **Настройки сайта.** Project settings (шестерёнка) → General → Your apps → значок `</>` (Web). Скопируйте значения `apiKey`, `authDomain`, `projectId`, `appId` в `public/config.js`. Там же можно вписать название школы.
5. **Публикация.** Установите [Node.js](https://nodejs.org), затем в терминале, в папке `school-portal`:
   ```bash
   npm install -g firebase-tools
   firebase login
   firebase use --add          # выберите свой проект
   firebase deploy --only hosting,firestore:rules
   ```
   Сайт появится по адресу `https://<ваш-проект>.web.app`.
6. **Первый администратор.**
   1. Зарегистрируйтесь на сайте как обычный пользователь — откроется экран ожидания.
   2. В консоли Firebase: Authentication → Users → скопируйте **User UID** своей почты.
   3. Firestore Database → Start collection → ID коллекции `admins` → Document ID = этот UID → добавьте любое поле, например `role` = `admin` → Save.
   4. Обновите сайт: вы в портале, появилась вкладка «Заявки». Ваша собственная заявка одобрится автоматически.

   Других администраторов добавляют так же. С сайта сделать себя администратором нельзя — это запрещено правилами.

## Безопасность

- Пароли хранит Firebase, сайт их не видит. Забытый пароль восстанавливается кнопкой «Забув пароль?».
- Чужие заявки видит только администратор. Ученик видит только свою.
- Читать и писать в чат можно только своего класса; подписаться чужим именем нельзя.
- Администратор может удалить любое сообщение или объявление.
- Сайт собирает минимум данных: имя, класс, необязательный контакт. Не просите адреса, телефоны детей и фото документов.
- Детям до 13 лет регистрироваться стоит вместе с родителями — по правилам Google и закону о защите данных нужно согласие родителей.

## Проверка на компьютере без публикации

```bash
firebase emulators:start --only auth,firestore,hosting --project demo-school
```
Откройте <http://localhost:5000/?emulator> — сайт работает с локальной тестовой базой, настоящий проект не трогается.
